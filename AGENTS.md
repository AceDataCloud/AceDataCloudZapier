# Ace Data Cloud Zapier

This repository owns the single Ace Data Cloud Zapier Platform CLI application. Use Node 22 and the pinned core/CLI versions. Commands: `npm ci`, `npm test`, `npm run validate`, `npm run validate:publish`, `npm run build`.

- Keep service names discoverable in specific action labels and tutorials, within Zapier branding rules. Do not create duplicate public apps using the same API and authentication solely for keyword discovery.
- Never describe private source, local tests, CI or an edited official screenshot as an uploaded version, public directory listing or successful Zap.
- Generation and editor action tests are paid; obtain explicit current execution authorization before live tests. Task retrieval only checks an existing ID. No model fallback or app-side generation retry.
- Use callback/resume for long media work; treat callbacks only as wake-ups and read the same task through the authenticated task API. Never expose pending preview URLs as final results or return token, callback URL or raw upstream errors.
- Preserve credentials outside Git. Developer deploy credentials and Ace API tokens are separate. Never print them or accept account/platform agreements on behalf of the owner.
- Bot commits: Ace Data Cloud Dev <dev@acedata.cloud>. Deliver changes through PRs, verify OPEN before each follow-up push, and do not merge without explicit authorization.
- Normal CI must discover the test tree; do not use per-file allowlists.
